# Kaan Taskent

I build practical AI products at the intersection of computer vision, process discovery, context engineering, and developer tools.

My projects are product experiments with real implementations, explicit limitations, and automated quality gates. I care about useful interfaces, local-first architecture where it makes sense, and evidence over demos that only look finished.

## Featured work

| Project | What it explores |
| --- | --- |
| [Ultra Vision](https://github.com/kaantaskentt/ultra-vision) | Local-first vision and a gesture-controlled two-deck DJ mixer in the browser |
| [Nexus](https://github.com/kaantaskentt/nexus) | AI interviews that turn human context into trust-tagged claims, workflow maps, and perception gaps |
| [RecordFlow](https://github.com/kaantaskentt/recordflow) | Evidence-linked process discovery for turning recorded work into automation-ready specifications |
| [LaunchDeck](https://github.com/kaantaskentt/launchdeck) | A local-first cockpit for importing, inspecting, editing, and safely previewing projects |
| [ContextOS](https://github.com/kaantaskentt/context-os) | An agent skill for compacting stale AI memory into high-signal working context |

- Reliable context and memory for AI agents
